# Проверка макета с фабрикой — 10 октября 2026

## Что изменено

- Игровой холст 540 × 1171 соответствует пропорциям макета Photoshop 1179 × 2556.
- Background-factory.png расположен сверху без изменения исходника. Остальной экран — серый асфальт #7C8089. Убраны отдельные панели конвейера, погрузки и парковки, заголовки секций и подписи кнопок.
- Пять погрузочных мест используют разметку рисунка; машины стоят под углом −27°.
- Полные габариты машин: общая ширина 56; длина 98,24 для 2 мест, 139,37 для 4 мест и 182,79 для 6 мест. Длины получены из прежнего замера PSD; средняя длина двух самосвалов объединена в один класс. Ширина намеренно выровнена по просьбе пользователя.
- Парковка занимает Rect2(35,660,470,430), середина проезда проходит на y=550. Повороты выполняются после полного выхода габарита машины из стоянки. Заполненные машины сначала выезжают задним ходом из наклонного места, затем поворачивают на свободном проезде.
- Подключены настоящие PNG досок, кирпичей, цемента, кабеля, труб и шифера. Исходные рисунки не изменялись.
- Рабочий в оранжевой каске останавливается у каждого предмета подряд идущей группы. Количество в руках растёт по одному; затем вся пачка переносится к задней части подходящей машины. Количество ограничено оставшимися местами. Учёт груза меняется атомарно только при доставке.
