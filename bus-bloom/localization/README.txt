ЛОКАЛИЗАЦИЯ CARGO YARD — первый этап подключения

ИСТОЧНИК И ОБНОВЛЕНИЕ
Таблица Cargo-Yard-localization.xlsx: вкладки EN, DE, FR, JA, KO, ZH, TR, PL, ES, AR.
Колонка C — постоянный ID; колонка B — перевод. Порядок строк не важен.
Запуск из bus-bloom:
  python tools/import_localization.py <путь к Excel>
Импорт проверяет ID и параметры до записи. Пустые переводы не стирают готовые;
отсутствующие в таблице записи сохраняются. Неизвестный ID требует добавления
в catalog.ru.json. Изменение исходника под тем же ID требует проверки переводов.
Новые ID должны быть смысловыми постоянными ключами. Старые ID сохраняем.
Старый extract_localization.py пока является инвентаризатором и не должен
перезаписывать утверждённый реестр при добавлении строк: его миграция ещё впереди.

ГЕНЕРИРУЕМЫЕ ФАЙЛЫ
runtime.json — словари, которые использует игра.
ru.po и 10 языковых PO — обмен с редакторами переводов; не редактировать их
параллельно Excel без обратного переноса изменений в таблицу.

В ИГРЕ
scripts/localization.gd: message(ID, parameters) для новых строк.
Именованные подстановки {amount}; зарезервированная иконка {{coin}}.
Существующие рисованные окна используют адаптер text(русский исходник):
точное совпадение или распознавание известных русских числовых шаблонов.
Новые механики должны обращаться по ID, без распознавания готового текста.
Язык выбирается из ОС/браузера. Для теста: --language=en после разделителя --
в командной строке Godot; для Web — параметр URL lang=en.
Если язык не поддерживается, используется английский.
ZH содержит упрощённый китайский, отдельной традиционной версии пока нет.

Иконки и текст проходят совместную раскладку TextLine/TextParagraph.
Для JA используется M PLUS Rounded 1c, для KO/ZH/AR — Noto с лицензиями
в assets/fonts/localization. Полные шрифты сохранены для новых строк.

ПРОВЕРЕНО
11 языков, динамические числа, монетка внутри строки, fallback языка.
Локальные снимки окон победы и нехватки монет: EN, JA, KO, ZH, AR.
Регрессионные проверки логики модальных окон.

Завершить миграцию оставшихся составных сообщений на явные ID.
Подключить выбор языка игроком с сохранением настройки.

не заменяет полную проверку всех переводов и всей геометрии интерфейса.
