# Звуки игры

- `music/menu.ogg` — главное меню; `music/game.ogg` — игровой уровень. Оба трека зациклены.
- `fx/*-download-single.wav` — каждый отдельный предмет при взятии с ленты.
- Доски → wood; кирпичи → bricks; цемент → cament; кабель → cable; трубы → pipe.
- Для профнастила временно используется pipe: отдельного файла для него нет.
- Партия в кузов: 1 → upload-one; 2 → upload-two, два последовательных воспроизведения; 4 → upload-four; 3, 5 и 6 → upload-many.
- `bump.wav` — момент видимого столкновения; `truck-full.wav` — заполнение последнего места.

Нота включает музыку, динамик — эффекты, телефон — вибрацию. Настройки независимы и сохраняются в прежнем файле прогресса. Выключение эффектов останавливает уже звучащие и ожидающие повторения звуки. Пауза игры приостанавливает эффекты; перезапуск отменяет их.

Вибрация: короткий отклик на столкновение и полную загрузку; зависит от возможностей платформы и устройства. Проверка на физическом телефоне ещё нужна.
